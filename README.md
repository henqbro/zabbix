-------------------------------------------------------------------------------
### Установка PostgreSQL
-------------------------------------------------------------------------------
```bash
sudo apt update
sudo apt install -y postgresql postgresql-contrib
sudo systemctl enable --now postgresql
```
-------------------------------------------------------------------------------
### Создание базы данных
-------------------------------------------------------------------------------
```bash
sudo -u postgres createuser --pwprompt zabbix      
sudo -u postgres createdb -O zabbix zabbix
```
-------------------------------------------------------------------------------
### Установка Zabbix Server
-------------------------------------------------------------------------------
`sudo apt install -y zabbix-server-pgsql zabbix-frontend-php php-pgsql zabbix-agent`

-------------------------------------------------------------------------------
### Импорт схемы
-------------------------------------------------------------------------------
```bash
zcat /usr/share/zabbix-server-pgsql/schema.sql.gz | sudo -u zabbix psql -U zabbix -d zabbix
zcat /usr/share/zabbix-server-pgsql/images.sql.gz | sudo -u zabbix psql -U zabbix -d zabbix
zcat /usr/share/zabbix-server-pgsql/data.sql.gz | sudo -u zabbix psql -U zabbix -d zabbix
```
-------------------------------------------------------------------------------
### Настройка сервера
-------------------------------------------------------------------------------
```bash
sudo nano /etc/zabbix/zabbix_server.conf

Параметры в файле:
DBHost=localhost
DBName=zabbix
DBUser=zabbix
DBPassword=zabbix123
```
-------------------------------------------------------------------------------
### Исправление ошибки с часовым поясом
-------------------------------------------------------------------------------
На этапе установки возникла ошибка — указал часовой пояс вручную:
`echo "date.timezone = Europe/Moscow" | sudo tee /etc/php/7.4/apache2/conf.d/99-zabbix.ini`

-------------------------------------------------------------------------------
### Настройка Apache
-------------------------------------------------------------------------------
```bash
sudo a2enconf zabbix-frontend-php
sudo a2enmod rewrite
sudo systemctl restart apache2
```
-------------------------------------------------------------------------------
### Запуск сервисов
-------------------------------------------------------------------------------
```bash
sudo systemctl restart zabbix-server
sudo systemctl enable zabbix-server zabbix-agent apache2
```
-------------------------------------------------------------------------------
### Создание конфигурационного файла
-------------------------------------------------------------------------------
```bash
sudo nano /etc/zabbix/zabbix.conf.php

Содержимое файла:
$DB['TYPE']     = 'POSTGRESQL';
$DB['SERVER']   = 'localhost';
$DB['PORT']     = '5432';
$DB['DATABASE'] = 'zabbix';
$DB['USER']     = 'zabbix';
$DB['PASSWORD'] = 'zabbix';
$DB['SCHEMA']   = 'public';
$ZBX_SERVER      = 'localhost';
$ZBX_SERVER_PORT = '10051';
$ZBX_SERVER_NAME = 'Zabbix 5.0 Server';

sudo chown www-data:www-data /etc/zabbix/zabbix.conf.php
sudo chmod 640 /etc/zabbix/zabbix.conf.php
```
Можно переходить на веб-интерфейс

-------------------------------------------------------------------------------
-------------------------------------------------------------------------------
### Установка агента
-------------------------------------------------------------------------------
```bash
sudo apt update
sudo apt install -y zabbix-agent
```
-------------------------------------------------------------------------------
### Настройка конфигурации
-------------------------------------------------------------------------------
```bash
sudo nano /etc/zabbix/zabbix_agentd.conf

Установлены параметры:
Server=158.160.192.162
ServerActive=158.160.192.162
Hostname=Zabbix client 1
```
-------------------------------------------------------------------------------
### Создание директории и файла лога
-------------------------------------------------------------------------------
```bash
sudo mkdir -p /var/log/zabbix
sudo touch /var/log/zabbix/zabbix_agentd.log
sudo chown zabbix:zabbix /var/log/zabbix/zabbix_agentd.log
sudo chmod 644 /var/log/zabbix/zabbix_agentd.log
```
-------------------------------------------------------------------------------
### Включение логирования
-------------------------------------------------------------------------------
```bash
sudo nano /etc/zabbix/zabbix_agentd.conf

Добавить:
LogFile=/var/log/zabbix/zabbix_agentd.log
DebugLevel=3
```
-------------------------------------------------------------------------------
### Перезапуск и включение автозапуска
-------------------------------------------------------------------------------
```bash
sudo systemctl restart zabbix-agent
sudo systemctl enable zabbix-agent
```
-------------------------------------------------------------------------------
### Проверка статуса
-------------------------------------------------------------------------------
`sudo systemctl status zabbix-agent`

-------------------------------------------------------------------------------
### Проверка, что агент слушает порт 10050
-------------------------------------------------------------------------------
```bash
sudo netstat -tulpn | grep 10050
или
sudo ss -tlnp | grep 10050
```
-------------------------------------------------------------------------------
### Просмотр логов
-------------------------------------------------------------------------------
`sudo tail -30 /var/log/zabbix/zabbix_agentd.log`

-------------------------------------------------------------------------------
### Проверка версии
-------------------------------------------------------------------------------
`zabbix_agentd --version`
